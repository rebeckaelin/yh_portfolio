# Personal Portfolio Website 🌟

This repository contains my personal portfolio website, showcasing my projects and skills as part of my capstone project for my education.

## Overview

This portfolio website serves as a central hub to display my work, skills, and experiences. It provides visitors with an easy way to explore my projects and learn more about my capabilities as a developer.

## Technologies Used 🛠️

The project is built with the following technologies:

- ![React](https://img.shields.io/badge/-React-61DAFB?style=flat-square&logo=react&logoColor=black) Frontend framework for building the user interface
- ![Tailwind CSS](https://img.shields.io/badge/-Tailwind%20CSS-38B2AC?style=flat-square&logo=tailwind-css&logoColor=white) Utility-first CSS framework for styling
- ![Sanity](https://img.shields.io/badge/-Sanity-F03E2F?style=flat-square&logo=sanity&logoColor=white) Headless CMS for content management
- ![Firebase](https://img.shields.io/badge/-Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=black) Backend services

## Features

- Responsive design that works on various devices and screen sizes
- Project showcase with detailed information and images
- Content management through Sanity studio
- Modern and clean UI built with Tailwind CSS

## Content Management

Content for projects and other sections is managed through the Sanity Studio, allowing for easy updates and additions to the portfolio without changing code.
